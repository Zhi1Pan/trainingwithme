??? info "科学说明与局限：这个模拟和真实训练差在哪？"
    - **教学性简化**：本模拟把「操作性条件作用、行为塑造、刺激辨别与泛化、人犬协作」压缩进三个关卡的少数几次决策，用于帮助理解概念，不等同于真实训练流程。真实的训练决策远不止三个选项。
    - **真实训练的基础**：现代导盲犬训练以**正强化（R+）**和 **LIMA（最少侵入、最少厌恶）**原则为主，训练周期以年计、重复次数以千计，并且存在较高的淘汰率——不是每条犬都适合成为导盲犬。
    - **协作是双向的**：犬提供物理提示（在台阶、路口前停步，身体偏向等），人负责综合判断与决策；导盲犬不会看红绿灯，也不能独立完成所有交通判断。协作是双向同步，而不是单向指令。
    - **福利框架**：评估训练方案可采用**五域模型**（营养、环境、健康、行为、心理状态）的视角。训练应是愉快且自愿参与的，不应依赖惩罚与疲劳。详见「参考文献与科学依据」页面（建设中）。
